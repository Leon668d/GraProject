Problem

SAR 与光学图像直接匹配困难

SAR 与光学图像的成像机理差异明显，同一地物在两种模态下的纹理、亮度和边缘响应并不一致。 本系统采用 Fake Optical 作为中间域，把跨模态配准问题转化为更接近光学图像之间的匹配问题。

数据样本池 6157 -> 4042

剔除海洋、水体、低纹理和近似空白样本。

默认推理参数 8 steps / 2048 kp

在效率与配准稳定性之间选择的默认配置。

Pipeline

完整方法链路

01 SAR 输入

上传或选择 Sentinel-1 SAR 图像。

02 扩散生成

预训练生成器输出 Fake Optical。

03 级联匹配

SuperPoint 优先，ALIKED 作为补充。

04 几何门控

按内点、RMSE、空间覆盖和单应矩阵形状复核。

05 SAR 配准

把匹配得到的几何关系迁移回 SAR。
